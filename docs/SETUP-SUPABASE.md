# دليل ربط قاعدة البيانات الإلكترونية (Supabase)

## 1) إنشاء المشروع
1. ادخل إلى https://supabase.com وسجّل حساباً مجانياً.
2. اضغط **New project**، اختر اسماً مثل `jadwaly` وكلمة مرور لقاعدة البيانات.
3. انتظر ثوانٍ حتى يكتمل إنشاء المشروع.

## 2) إنشاء الجداول
1. من القائمة الجانبية افتح **SQL Editor** → **New query**.
2. الصق محتوى ملف `setup-supabase.sql` كاملاً واضغط **Run**.
3. سيتم إنشاء جدولين:
   - `plans`   (الباقات: أسبوعي / شهري / سنوي + أسعارها)
   - `clients` (العملاء وحساباتهم واشتراكاتهم)

## 3) الحصول على المفاتيح
1. افتح **Project Settings** → **API**.
2. انسخ **Project URL** و **anon public key**.
3. افتح ملف `supabase-config.js` وضعهما في مكانيهما:
   ```js
   window.SUPABASE_CONFIG = {
     url: 'https://xxxx.supabase.co',
     anonKey: 'eyJhbGciOi...'
   };
   ```
   يمكنك أيضاً تغيير بيانات دخول الإدارة من نفس الملف (افتراضياً `Ahmed` / `1985@1985`).

## 4) الرفع والنشر
- ارفع التغييرات إلى مستودع GitHub: `abubesun-hub/Time-table`
- فعّل GitHub Pages (Settings → Pages → Branch: main)
- رابط الموقع: `https://abubesun-hub.github.io/Time-table/`

## كيف يعمل النظام
| الصفحة | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية: الأسعار + تسجيل الدخول |
| `admin.html` | إدارة الموقع: إضافة العملاء وتفعيل اشتراكاتهم وتعديل الأسعار |
| `app.html` | نظام جدولي — لا يفتح إلكترونياً إلا بحساب مفعّل (بوابة دخول) |

## ملاحظة أمنية
الإدارة تتم من الواجهة (كلمة مرور المسؤول داخل `supabase-config.js`)، وRLS معطّل على الجدولين لسهولة التشغيل. هذا مناسب لهذا النطاق من الاستخدام، ولزيادة الحماية يمكن لاحقاً تفعيل RLS وكتابة سياسات أكثر صرامة.
